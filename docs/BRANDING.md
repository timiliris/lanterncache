# LanternCache identity

The blue lantern combines a download spark with glowing storage rings. It follows the application's midnight navy and electric blue palette.

`assets/lanterncache-icon.png` is the original generated raster, used by the sidebar, browser favicon, Apple touch icon and README. It was created with OpenAI's built-in Image Gen tool, rather than a CLI/API fallback. The project MIT license covers this original project asset. Third-party game artwork visible in screenshots retains its owners' rights.

## Generation prompt

> Create one premium app icon for LanternCache, an independent home Steam game download cache dashboard. Square 1024 composition. A bold unmistakable lantern silhouette whose center glows with an electric ice-blue stylized lightning bolt / flowing download spark, cleverly combining a lantern and data cache. Dark midnight navy squircle tile, crisp bevelled brushed metal perimeter, cyan and azure light, subtle blue ambient halo, sophisticated gaming software visual identity. Strong simple silhouette, confident clean geometry and very few details so readable at 32 px. High-end restrained 3D material rendering, front view, centered, icon fills 80% of canvas, generous clean corners. No letters, no words, no Valve or Steam logo, no green, no watermark. Entire image is the icon itself, no mockup or scene.
